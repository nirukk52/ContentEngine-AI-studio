# Avatar Content Engine (ACE)

ACE is a **style-first avatar video factory**.

It turns a script (or reference video style) into a **repeatable channel output**:
scene-planned, captioned, paced, variant-tested, and graded using evals.

## Why this exists
Most tools can generate an AI avatar video.
Almost none can generate **your exact creator style** consistently and improve it over time.

ACE is the missing layer:
**Style Pack + Evals + Variants → compounding quality.**

## What ACE produces
Given a script:
- Scene Map (6–12 beats)
- Styled captions (kinetic rules)
- Background plan (tag-based selection)
- Avatar placement plan (on/off/PIP rules)
- 2–3 variants (hook/caption density/energy)
- Eval scorecard + winner selection

## Key Concepts

### 1) Style Pack
A versioned ruleset that defines a channel/series:
- scene template
- caption rules
- timing/pacing rules
- background tags
- scoring rules
- variant generation rules

### 2) Scene Map
A beat-by-beat plan:
- hook → context → proof → explain → takeaway → CTA

### 3) Eval Scorecard
Numeric scoring (1–10) across:
- hook strength
- style match
- rhythm
- caption quality
- clarity
- proof integrity
- repetition risk

### 4) Variants
Every run can produce multiple versions and auto-pick the best.

## What ACE is NOT
- Not just a video editor
- Not just a posting tool
- Not “automation templates”

ACE is **a channel OS**.
